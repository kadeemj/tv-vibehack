# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/hisense-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/hisense-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#

# packages run the tuner, inputs and picture pipeline; leave them alone.

# Known quirk: Play Protect blocks sideloaded apps that target an old SDK ("built for an older version of
# Android"), so the launcher must target a current SDK on this firmware.
